# Stash documentation

Stash is a place for your files that you run yourself, on your own computer or NAS. It can also
collect files from other people and send files to them, without anyone seeing more than you allow.

- **[Installing Stash](installing.md):** start it, choose your password, keep your files safe,
  update it, start it automatically and put it on the internet.
- **[Using Stash](using.md):** your files, upload links to ask people for files, share links to send
  them files, and the command line for very large files.
- **[Technical guide](technical.md):** how Stash works, running it behind a reverse proxy,
  blocking password guessers with fail2ban, the security model, the HTTP interface, and developing
  Stash.

The source code, releases and issues are on [GitHub](https://github.com/dvdstelt/stash).
